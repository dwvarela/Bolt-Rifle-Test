# M700 Bolt-Action Rifle (NeoForge 21.1.257 / Minecraft 1.21.1) - v2.0

Animated bolt-action rifle with scoped aiming, 5-round magazine, craftable rifle and ammo.

> **Status:** compiled by GitHub Actions only; nothing here has been run in-game yet.
> v1.0 (the simple version) worked. v2.0 adds GeckoLib animations, so it is new, untested code.

## You need GeckoLib too

v2.0 depends on **GeckoLib 4.7 or newer (4.x) for NeoForge 1.21.1** (built against 4.9.3;
`geckolib_version` in `gradle.properties`; if that exact version can't be found, use `4.7.2`). Put the GeckoLib jar in your `mods`
folder next to `boltrifle-2.0.0.jar` (get it from Modrinth or CurseForge: search "GeckoLib",
pick NeoForge + 1.21.1). Remove the old v1 rifle jar first.

## Controls

| Input | Action |
|---|---|
| **Left click** | Fire (bolt cycles automatically after each shot) |
| **Hold right click** | Aim down the scope |
| **Scroll wheel** (while scoped) | Zoom 3x - 12x |
| **R** | Reload (rebind in Controls > "Bolt-Action Rifle") |

Magazine holds **5**, plus **1 in the chamber** (a full load shows `5/5 +1`). Reloading
from empty plays the magazine swap, then the bolt cycle that chambers a round. Reloading
with a round already chambered only swaps the magazine. Switching items mid-reload cancels
it and gives the rounds back. Headshots do 1.5x. Hip fire is inaccurate; scoped is precise.

## Recipes (unchanged)

**Rifle:** `III / WT. / W..` with I = iron ingot, W = planks, T = tripwire hook.
**Rounds (x4):** iron nugget + gunpowder + copper ingot (shapeless).

## Build

Push the project to GitHub; the included workflow (`.github/workflows/build.yml`) builds it.
Download the `boltrifle-jar` artifact from the Actions run. Or locally: JDK 21 + `gradle build`.

## Tuning the look WITHOUT rebuilding

Run the game once, then open **`config/boltrifle-client.toml`**. You can edit it while the game
is running and the change shows instantly. Each view has `scale`, `x/y/z` (blocks) and
`rotX/rotY/rotZ` (degrees):

- `[first_person]` where the rifle sits when held
- `[aiming]` where it slides to as you raise the scope
- `[third_person]`, `[gui]` (inventory icon), `[ground]`, `[fixed]` (item frames)
- `[scope]` default / min / max zoom and how much the mouse slows when zoomed
- `recoilPitch` camera kick

## Known guesses to check in game

- **Bolt handle direction:** if the handle swings *down* instead of up, change `HANDLE_LIFT`
  to `-75.0` in `tools/gen_anim.py`, run `python3 tools/gen_anim.py src/main/resources`, rebuild.
- Hand/rifle placement and the inventory icon angle are first guesses: use the config above.
- Model and animations are generated by `tools/gen_model.py` and `tools/gen_anim.py`.
